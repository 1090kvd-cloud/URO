Пузырьковый уровень с горизонтальной, вертикальной и круглой колбами, градусными шкалами наклона и поворота. Калибровка, фиксация показаний, звуковой контроль и четыре темы оформления.

Android 8.0 и новее. Русский и английский языки. Без рекламы и интернета.

Для установки скачайте файл **Uroven-1.3.0.apk** и откройте его на телефоне.
