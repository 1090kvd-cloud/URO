# Уровень

Пузырьковый уровень для Android с горизонтальной, вертикальной и круглой колбами, градусными шкалами наклона и поворота.

**[Скачать APK](https://github.com/1090kvd-cloud/URO/releases/download/v1.4.0/Uroven-1.4.0.apk)**

Калибровка, фиксация показаний, звуковой контроль, поворот плашмя с кнопкой 0° и четыре темы оформления. Русский и английский языки. Без рекламы и интернета.

Android 8.0 и новее. Скачайте APK и откройте его на телефоне для установки.
