# Уровень

Нативный пузырьковый уровень для Android 8.0 и новее. Русский и английский языки, автоматический выбор языка телефона и ручное переключение в настройках.

## Установить на телефон

[**Скачать Uroven-1.2.0.apk**](downloads/Uroven-1.2.0.apk?raw=true)

Откройте ссылку и скачайте APK (если GitHub показывает страницу файла, нажмите Download raw file). Откройте скачанный файл на телефоне и разрешите установку для приложения, через которое открываете APK. Root и Shizuku не нужны.

Название приложения — «Уровень» при любом языке интерфейса. Версия 1.2.0: звуковой контроль горизонтальной и вертикальной колбы по отдельности. Настройки → Звуковой контроль: автоматически, обе оси, горизонтальная колба X или вертикальная Y. Режим сохраняется; его также можно выбрать долгим нажатием кнопки звука. По умолчанию — автоматически: лёжа контролируются обе оси, приподнят верх/низ — X, боковая сторона — Y. Сигнал 400 мс; при включении звука есть пробный сигнал. Доступны четыре темы оформления. Настройки → Тема оформления: классическая зелёная, янтарная, ледяная синяя и светлая. Выбор сохраняется; переключение темы не сбрасывает фиксацию и калибровку. Сборка с подписью для разработки. Исходный код и APK находятся в одном репозитории. У приложения нет разрешения на Интернет, рекламы и аналитики.

## Возможности

- Горизонтальная, вертикальная и круглая колбы с плавным движением к приподнятой стороне.
- Наклоны X/Y в градусах, цифровой индикатор.
- Калибровка нуля по проверенной горизонтальной поверхности; сохранение после закрытия.
- Фиксация текущего показания и отключаемый звуковой сигнал при выравнивании.
- Допуск индикации: 0.1°, 0.3°, 0.5° или 1°. Это порог сигнала, а не гарантированная точность.
- Датчик гравитации; при его отсутствии — акселерометр. Если датчик недоступен, показания не подменяются демонстрацией.
- Экран остаётся включённым во время измерения; датчики и звук освобождаются при сворачивании.

Оформление самостоятельно нарисовано средствами Android Canvas по предоставленному визуальному образцу; чужие графические ресурсы и код не включены.

## Измерение

Положите заднюю сторону телефона на поверхность. Выступ камеры и неровный чехол могут давать ошибку: используйте плоскую проставку или рейку. Не перемещайте телефон во время измерения. X — направление влево/вправо, Y — вдоль телефона. Калибруйте только по известной горизонтали. Проверьте результат, развернув телефон на той же поверхности на 180°.

Фиксация удерживает показание до нажатия «Отпустить». После сворачивания и повторного открытия измерение запускается заново, фиксация снимается. Язык: Настройки → Язык. Сигнал использует громкость мультимедиа: её регулируют кнопки телефона при открытом приложении. Уровень генератора повышен с 35 до 100, сигнал увеличен с 100 до 400 мс. Общая громкость системы автоматически не меняется. Если подключены наушники или Bluetooth, проверьте выбранный вывод звука.

## Проверено

- 89 проверок расчётов и звукового контроля: углы, все четыре поворота экрана, отрицательная Z, калибровка, фиксация, нулевые/NaN-входы, фильтр при разных частотах, обнаружение движения и направления пузырьков.
- Сборка Java и Android-ресурсов SDK 35, преобразование DEX, выравнивание APK.
- Подписи APK v2/v3, пакет `com.kvd.bubblelevel`, minSdk 26, targetSdk 35; русская и английская локализации.
- На реальном устройстве и эмуляторе приложение пока не запускалось. Точность датчика, фактический вид интерфейса и звук требуют проверки на телефоне. Сборка Gradle отдельно не проверялась.

## Собрать

### Быстрая сборка без Gradle

Нужны Python 3, JDK 17+, Android SDK с пакетами `platforms;android-35` и `build-tools;35.0.0`.

```sh
export ANDROID_SDK_ROOT=/path/to/android-sdk
sh scripts/test.sh
python3 scripts/build-apk.py
```

APK: `build/Uroven-1.2.0.apk`. Скрипт создаёт локальный ключ для разработки в `~/.android/kvd-level-debug.keystore` либо использует путь `LEVEL_DEBUG_KEY`. Не публикуйте закрытый ключ и не используйте этот ключ разработки для промышленного релиза.

### Android Studio

Откройте корень проекта. Версии: Android Gradle Plugin 8.9.2, Gradle 8.11.1, JDK 17, SDK 35. Wrapper не включён: укажите локальную установку Gradle 8.11.1 в настройках Studio или выполните `gradle wrapper --gradle-version 8.11.1` установленным Gradle. Затем Build → Build APK(s).

### GitHub Actions

Workflow `Build Android APK` проверяет модель, собирает и проверяет APK при push в main или ручном запуске. Скачайте артефакт `Uroven-APK` со страницы завершённого запуска.

В CI по умолчанию создаётся новый ключ разработки на каждом запуске. APK из разных запусков и APK из `downloads/` имеют разные подписи: для перехода между ними потребуется удалить старое приложение (с потерей его локальных настроек). Для обновлений с сохранением данных нужен один постоянный закрытый ключ; перед публикацией в магазине настройте отдельную подпись релизов. Закрытые ключи в репозиторий не включены.

## English

Уровень is a native Android 8+ spirit level with three animated vials, X/Y inclination, calibration, reading hold, optional level beep, and English/Russian UI. No Internet permission, ads, or analytics. Install the development APK linked above. Accuracy depends on the device and reference calibration; no real-device test has been performed yet.

## Privacy

Only sound alignment mode, theme, language, zero offsets, tolerance and sound preference are stored locally. No account, network, location, camera, microphone, or storage permission is requested.
