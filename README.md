# Уровень

Пузырьковый уровень для Android с горизонтальной, вертикальной и круглой колбами.

**[Скачать APK](https://github.com/1090kvd-cloud/URO/releases/download/v1.2.0/Uroven-1.2.0.apk)**

Калибровка, фиксация показаний, звуковой контроль и четыре темы оформления. Русский и английский языки. Без рекламы и интернета.

Android 8.0 и новее. Скачайте APK и откройте его на телефоне для установки.
